# 会话 API 汇总（api-summary）

CC GUI（ccgui-next）Tier-1 JS 插件。在侧栏「会话」右键菜单里新增 **「汇总API」**：
把一段可配置的提示词交给 AI，让它梳理本次会话涉及的接口，并落地成两份产物：

1. **接口台账** `docs/apis.xlsx`（相对当前工作空间），固定 8 列：
   `接口编码 · URL · Url所在Controller · 请求方式 · 接口含义 · 接口含义简要描述(≤10字) · 归属任务 · 其他备注`
   接口编码规则：`前缀 + 年月(yyMM) + 两位流水号`，如 `CS261001`（前缀可改）。
2. **接口文档** `docs/apis/<归属任务>/<接口编码>_<简要描述>.md`，每篇必含
   **业务流程图 / 表数据流转图 / 业务时序图 / 其他标注**，并对 Mermaid 代码块做
   「标记闭合 / 语法规范 / 无孤立节点 / 成对结构有 end」的渲染自检。

两段提示词（汇总提示词、文档输出逻辑）都有默认值，且**均可在设置页自定义**。

## 为什么靠 AI 而不是插件自己写文件

插件层没有文件系统 API，而「读懂这段对话 → 抽接口 → 写 xlsx → 画 Mermaid 并自检」本质是需要
完整上下文的生成任务。所以插件负责**编排**（把带上下文变量的提示词送达 AI），落盘由 AI 用
openpyxl / 写文件完成。两种送达方式（设置页切换）：

- **草稿（默认，推荐）**：右键后自动切到该会话，把提示词填进输入框，你按回车发送。
  AI 带着这轮会话的完整历史来汇总，**最准确**。
- **自动发起轮次**：直接起一个宿主可见的聊天轮次（可随时停止/接管）。注意它可能是新会话、
  看不到原始历史，准确性略低。

## 安装 / 更新 / 卸载

- **安装**：CC GUI 侧栏「插件」→「从本地目录安装」→ 选中本目录（含 `manifest.json` 这一层）。
- **更新**：改完 `main.js`/`manifest.json` 后**重新走一遍「从本地目录安装」**即可热重载（同 id 覆盖），无需重启。
- **卸载**：插件页对该行点卸载即可。

## 配置项（设置 → 会话 API 汇总）

| 项 | 默认 | 说明 |
|---|---|---|
| 送达方式 | 草稿 | 草稿 / 自动发起轮次 |
| 接口编码前缀 | `CS` | 编码 = 前缀+yyMM+流水号 |
| 台账 Excel 路径 | `docs/apis.xlsx` | 相对工作空间 |
| 接口文档目录 | `docs/apis` | 相对工作空间 |
| 汇总API 提示词 | 内置 | 可编辑，「恢复默认」一键还原 |
| 接口文档输出逻辑提示词 | 内置 | 可编辑，「恢复默认」一键还原 |

提示词占位符：`{workspace}` `{xlsx}` `{dir}` `{prefix}` `{engine}` `{sessionId}`。
