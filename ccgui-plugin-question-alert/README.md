# question-alert · 会话提醒

会话结束、报错、或停下来等你回答时，给你一条**可定制的**提醒：标题与正文由你自己写模板，聚焦时是应用内卡片（跟随主题明暗），失焦时是系统 Toast（同一份模板）。

## 三类事件

| 事件 | 覆盖 | 卡片 | 系统 Toast |
|---|---|---|---|
| 智能体完成 | 一轮任务正常结束 | 绿色，6 秒退场 | 失焦时发 |
| 智能体错误 | 执行异常 / 会话中断 | 红 / 橙，常驻 | 失焦时发 |
| 智能体提问 | AskUserQuestion / 计划审批 / 权限请求 | 蓝，答完即消失 | 失焦时发 |

**没有子代理完成**——宿主不派发该事件，做不了。

## 模板变量

```
{project_name} {worktree} {branch} {session_name}
{agent_name}   {model_name} {last_message}
```

| 变量 | 来源 | 说明 |
|---|---|---|
| `session_name` | 宿主通知标题前缀 / 侧栏行标签 | 最稳 |
| `last_message` | 宿主通知正文；卡片路径回落本轮累积输出 | Toast 路径更准 |
| `project_name` / `worktree` | 当前工作区路径末段 | 只反映活动工作区 |
| `branch` | 工作区元数据 / 侧栏行 props | 后台其他工作区的会话可能为空 |
| `model_name` | engine `kind:"model"` 事件 | 收到过才有值 |
| `agent_name` | **固定为空**（主代理没有名字） | 默认模板会渲染成「已完成」 |

渲染规则：

- 缺变量替换为空串，**绝不把 `{xxx}` 漏给用户**。
- 渲染结果为空时回落到该事件的内置默认模板；仍为空则用兜底文案。
- 模板里写了 `{last_message}` 但该变量为空时，正文保留兜底，不发出空白提醒。

## 双路径投递

```
 engine 事件 ──► 应用内卡片（聚焦时）
                 ▲ 不受宿主通知开关约束，永远可用
 宿主通知 ────► 拦截改写 ──► 系统 Toast（失焦时）
                 ▲ id / sessionKey 原样保留，点击仍跳会话
```

同一事件只响一次：聚焦时 Toast 被丢弃，失焦时卡片不画。

## 设置

设置 → 插件 →**会话提醒**（宿主把插件页固定放在「插件」分组，无法并入「系统」分组）：

- **通知投递**：总开关、应用聚焦时也发系统通知、发送测试通知。
- **通知事件**：三个独立勾选框。
- **通知模板**：每个事件一组「标题 / 消息」，可恢复默认，下方有变量提示与实时预览。
- **诊断**：订阅状态、Toast 改写是否安装、已改写 / 前台转卡片 / 未识别 的计数。

测试按钮会**同时**弹一张卡片和一条真系统 Toast——一次点击验证两条通道。

## 能力边界（诚实交代）

| 依赖 | 失效后果 | 如何察觉 |
|---|---|---|
| `engine://event` 原始事件流（非官方契约） | 卡片与侧栏高亮不再出现 | 诊断「订阅」字段 |
| 宿主通知标题尾缀（`· 对话已完成` 等，中英韩三套） | Toast 退回宿主原文，卡片不受影响 | 诊断「未识别 N 条」 |
| `plugin:notification\|notify` 的 `options.id` / `extra.sessionKey` | Toast 点击只聚焦窗口，不跳会话 | — |
| `__TAURI_INTERNALS__.invoke` 可被包装 | 完全不改写，系统 Toast 用宿主原文 | 诊断「Toast改写: unsupported」 |

另外：

- 包装的是 hardening 之后那个 invoke，插件自身调用仍被深度检查拦下——安全边界不变。
- 卸载即还原，配置留在插件 KV，重装后仍在。
- `{branch}` 对后台其他工作区的会话可能为空（`getMetadata()` 只答当前工作区）。

## 本机部署

三个文件即完整 bundle。改完走 **设置 → 插件 → 从本地目录安装**（同 id 覆盖热重载）。卡片样式在 `activate` 里自注入，改磁盘文件即时生效。

## 自测

1. 设置 → 插件 →「会话提醒」→「发送测试通知」：应同时看到卡片与系统 Toast，且文案一致。
2. 把完成事件的标题改成 `{project_name}/{branch} 完成`，再点测试——预览与两条提醒都应跟着变。
3. 新开一个会话让它 `AskUserQuestion`，切走窗口：系统 Toast 出现；切回点该行：卡片在。
4. 切到暗色主题，三种卡片应整体变深色。
